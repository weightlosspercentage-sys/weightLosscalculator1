# Weight Loss Percentage Calculator

A modern, clinical-grade React application for calculating, tracking, and visualizing body weight loss percentage, metabolic health landmarks, and fair group competitions.

## Core Features

- **Instant Weight Loss Percentage Calculation**: Live calculation using the clinical standard formula `((Start Weight - Current Weight) / Start Weight) * 100`. Supports pounds (lbs), kilograms (kg), and stones & pounds (st/lbs).
- **Clinical Health Milestones Roadmap**: Detailed tracking towards 5%, 10%, 15%, and 20% metabolic reduction landmarks backed by clinical trials (blood pressure, glycemic regulation, sleep apnea reduction, liver lipid reduction).
- **Interactive Weight History & Graphs**: Visual trajectory chart powered by Recharts with milestone reference lines, cumulative % lost, and CSV export.
- **Fair Group Challenge Leaderboard**: Normalizes competition across different body weights for workplace pools and family challenges.
- **BMI & Health Classification**: Start vs current BMI shift tracking.
- **Calorie Deficit & Pace Estimation**: Weekly loss rates (lbs/kg per week) and estimated total and daily calorie deficits based on 3,500 kcal per lb fat.
- **Printable Medical Report**: Clean summary format for medical visits, nutritionists, or personal records.

## Technology Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS
- Recharts
- Lucide React
- Canvas Confetti
